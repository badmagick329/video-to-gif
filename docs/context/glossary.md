# Glossary

The project's ubiquitous language, one row per concept; the index's *Language* section says how to use it. Sorted by term.

| Term | Meaning | Avoid | In code |
| --- | --- | --- | --- |
| Caption | A meme-style top or bottom line of text, drawn in Anton (or a system face for non-Latin text) at a share of the output's shorter side. The preview draws it; Export renders it to a PNG at the exact output size for export to overlay. | text overlay, subtitle | `editor/lib/captions.ts` |
| Copy | Putting an output on the Windows clipboard as a file (`CF_HDROP`), from its button in the session list, so it pastes into an Explorer folder as a copy or into a chat app as an attachment. Only outputs this session made can be copied. | copy path, copy link | `copy_output`, `export::infrastructure::clipboard` |
| Crop | The rectangle of the source's frame an export keeps, stored as fractions of the frame so it means the same on a proxy; its pixels are those fractions of the displayed size. | | `ClipCrop`, `VideoCropper.tsx` |
| Destination | The folder an export puts its outputs in: the source's folder, unless the user picked one with Save to (the UI's name for the picker), which is remembered across launches while it exists. Outputs never overwrite a file there: a taken name gets ` (1)`, ` (2)` and so on. | output folder, save location | `run_export`'s `destination`, `useDestination.ts`, `export::infrastructure::destination` |
| Direction | How the selection plays in the output: forward, reverse, or boomerang (forward then backward, twice as long). The output preview always plays forward and labels the others. | | `OutputSettings.direction` |
| Displayed size | A source's width and height as shown: the coded size with rotation metadata applied, so a quarter turn swaps them. Crop rectangles and output sizes are in these pixels, because ffmpeg auto-rotates before any filter. | coded size (that is the pre-rotation size) | `SourceInfo.width`/`height` |
| Editor | The app's one window: toolbar, viewer over the timeline dock, inspector on the right, status bar. It never scrolls as a page; only the inspector's body scrolls. Every setting is always available: there is no simple mode. | advanced mode (mgck's name for its full editor), expert mode | `Editor.tsx` (the window), `SourceEditor.tsx` (with a source open) |
| Export | Running ffmpeg on the source, with the selection, crop and settings, to produce one or more outputs. Always reads the source, never the proxy. | convert, render, encode | `export` slice |
| Export footer | The inspector's pinned bottom under the Output tab: the size estimate per ticked file type, the frame-memory warning, Save to, and the Export button (Export anyway when the guard warns), which becomes the run's overall progress bar and Cancel while an export runs; that bar and Cancel are pinned under the Exports tab too. | convert panel | `ExportFooter.tsx`, `RunProgress` |
| Export request | What the Export button hands to export: source path, its source info, selection, crop, settings, whether to keep sound, the caption image, and whether the user accepted paging. The size estimate takes the same request. Export works out the output size and length from these itself. | job | `ExportRequest` in `editor/lib/types.ts`, `export::domain::plan::ExportRequest` |
| Exports tab | The inspector's second tab: the running card while an export runs, over the session list. Its badge counts this session's outputs. Starting a run never switches to it. | results tab, history | `Inspector.tsx` |
| File type | GIF, WebP or MP4, toggled in any mix in the inspector's Format section; each ticked one becomes an output. mgck's name, kept because "output format" named a simple-mode preset there. | output format | `FileType` |
| Frame-memory guard | The warning shown when an export's held frames (a GIF's palette queue, Reverse, Boomerang) would exceed the machine's free memory, so Windows would page; Export becomes Export anyway, and export refuses such a run only when the request lacks that acceptance. mgck's frame-memory limit, with free RAM as the budget instead of a fixed Wasm one. | memory limit | `export::domain::memory`, `estimate_export_memory`, `acceptPaging` |
| Inspector | The 340 px panel on the window's right, beside the viewer and the timeline dock. Its Output tab holds the output settings in sections (Format, Size, Timing, Transform, Captions, GIF quality & looping) over the export footer; its Exports tab holds the running card and the session list. | sidebar, settings column | `Inspector.tsx`, `OutputSettingsForm.tsx` |
| In point, out point | The selection's first and last times. Set with I and O (Set in, Set out), typed into the dock's In and Out fields, or dragged as the track's handles; edits made with the pointer land on a frame boundary. | start and end, in UI copy (the code's `ClipTrim` keeps `start` and `end`) | `ClipTrim.start`/`end`, `setSelectionStart`/`End` in `editor/lib/trim.ts` |
| Output | A GIF, WebP or MP4 file produced by an export. One export can produce any mix of the three; the session list shows them. Named after the source with the file type's extension. Open, Show in folder and Copy act only on outputs this session made. | | `ExportOutput`, `export::application::session_outputs` |
| Output preview | The live canvas in the viewer's Output pane showing the selection as it will encode: crop, size, rotation, flips and captions, at the chosen speed. Drawn from the player's frames, so it follows a proxy too. | preview (alone, that is the player) | `OutputPreview.tsx`, drawn by `SourceEditor.tsx` |
| Output settings | The user's explicit choices for the outputs: file types, width, frame rate, speed, direction, rotation, flips, captions, GIF colours, dithering and plays, WebP quality, MP4 sound. Nothing targets a size. Width, timing, quality and caption size carry over to the next source; the rest reset. | advanced settings | `OutputSettings`, `editor/lib/output-settings.ts`, `export::domain::settings` |
| Partial file | An output while ffmpeg writes it, under a temporary name (`<stem>.part-<pid>-<n>.<ext>`) in the destination. Renamed to the output's name on success, deleted on failure or cancel. | temp file | `export::infrastructure::outputs` |
| Preview source | What the editor's video player plays: the source itself when WebView2 can decode it, otherwise its proxy. | | `preview::domain::PreviewSource`, `open_source` command |
| Probe | Reading a source's metadata with ffprobe and validating it into source info. | inspect, analyse | `probe` slice, `probe_source` command |
| Proxy | A reduced H.264 copy of the source (at most 720 high, a keyframe a second), made by ffmpeg for preview only, never exported, kept in the temp folder while its source stays open. UI copy calls it a "preview copy", a phrase users understand. | transcode, preview file | `preview` slice, `make_proxy` command |
| Recent | The last 8 sources opened, newest first, listed in the start state with each one's folder, duration and when it was opened, and a remove button. Kept across launches; a file that no longer exists drops off when the list loads. Reopening an entry takes the same route as a dialog pick. | recent files, history | `recent_sources`, `preview::infrastructure::recent`, `StartView.tsx` |
| Running card | The Exports tab's card for the running export, like a render queue: a row per ticked file type, finished ones with ✓ and their size, the one being made with percent, time left, size estimate and a bar, the rest Queued. | job list | `RunningCard.tsx`, `ExportJob` in `editor/lib/export-run.ts` |
| Selection | The trimmed time range of the source that an export uses, from its in point to its out point. Whole video clears it. | clip, trim range, range | |
| Session list | The Exports tab's list headed *This session*: every output this session made, newest first, with a thumbnail, name, format · W × H · size, and Open, Show in folder and Copy, plus each file type that failed with its reason folded away. Opening another video keeps it. | Made this session (v0's heading), results screen, history | `SessionResults.tsx`, `SessionResult` |
| Setup message | What the app shows in place of its main view when `ffmpeg` or `ffprobe` is missing from PATH or does not run; it names which and how to install them. | error screen, onboarding | `SetupMessage.tsx`, `find_ffmpeg` command |
| Shared kernel | Crate-level Rust modules outside every slice that any slice may use: `process.rs` and `search_path.rs`, which find and start ffmpeg and ffprobe, and `temp_folder.rs`, the session temp folder. | common, utils | `crate::process`, `crate::search_path`, `crate::temp_folder` |
| Shortcuts overlay | The list of keyboard shortcuts over the window, opened with `?` or the status bar's Shortcuts button and closed with Escape. | hint row | `ShortcutsOverlay.tsx` |
| Size estimate | The expected bytes of each ticked file type's output, shown as "≈ size" in the export footer before Export. Rust works it out from sample encodes of the export request in the background; the app reports the figure and never judges it against a limit. | size prediction, target size | `estimate_output_size`, `export::domain::estimate`, `useSizeEstimate.ts`, `ExportFooter.tsx` |
| Source | The user's video, opened by path through drag-drop, a file dialog or Recent; any file the user's ffmpeg can read. Never copied or modified. One is open at a time; opening another replaces it. | input, upload | `editor/useSource.ts` |
| Source info | A source's validated metadata: duration, displayed size, frame rate, video codec, container and the first audio stream's codec (none when silent). | metadata, probe result | `probe::domain::SourceInfo` |
| Tap | A second, null output in an export's ffmpeg run that takes the selection's frames before a filter that holds them (a GIF's palette, Reverse) and reports their times, so progress moves while the input is read. Writes no file. | progress output | `export::domain::progress`, `job_args` |
| Temp folder | `%TEMP%\video-to-gif`, where the app keeps proxies, thumbnails, an export's caption image and a size estimate's samples: one session folder per running app, swept of crashed sessions at startup and deleted at exit. | cache, scratch dir | `crate::temp_folder` |
| Start state | The editor with nothing open: the drop zone with Open video and Recent in the viewer, an empty timeline track, and an inspector that says what carries over to the next source. A drop anywhere on the window opens a file, here or with a video open. | landing page, home screen | `StartView.tsx` |
| Thumbnails | Frames along the timeline dock's track, made by ffmpeg from the preview source: a strip of 24 across the whole source and, while the timeline is zoomed, strips of 24 across the span in view. Kept in the temp folder while the source is open. | strip, filmstrip | `make_thumbnails` command |
| Timeline dock | The panel under the viewer: a header with the selection's In and Out fields, its length, Set in, Set out, Whole video and the zoom slider, over the ruler, the track (thumbnails, the selection with its handles, the playhead) and, when zoomed, a scrollbar. Zooms from the whole source down to 48 frames across the track. | timeline area, trimmer, trim timeline | `TimelineDock.tsx`, `TimelineTrack.tsx`, `editor/lib/timeline.ts` |
| Viewer | The large area left of the inspector: a header with the mode switch and the crop controls, the stage, and the transport row. Its mode is Source (the player with the crop box), Output (the output preview filling the stage) or Side by side (both, the default); the last mode is remembered across launches. | player (that is the `<video>` inside it), preview pane | `Viewer.tsx`, `VideoTrimmer.tsx` |
