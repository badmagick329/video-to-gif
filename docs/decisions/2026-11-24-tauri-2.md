# Tauri 2 with a React frontend

Status: Accepted (2026-11-24).

## Context

The app needs a desktop shell that runs ffmpeg natively and plays video in an editor. mgck's advanced-mode editor already exists in React, TypeScript and Tailwind ([the UI decision](2026-11-24-ui-copied-from-mgck.md)). The candidates were Electron, Tauri, and a pure-native Rust GUI such as egui or iced.

## Decision

Tauri 2: a Rust backend, and a React + TypeScript + Vite + Tailwind frontend in the system webview, WebView2 on Windows.

- Over Electron, for install size and startup: Tauri uses the webview the OS already ships instead of bundling Chromium and Node.
- Over a native Rust GUI, because the editor UI already exists in React, and a native GUI would need its own video player, which would be most of the work.

## Consequences

- The webview is the video player, so WebView2's codec support decides what plays directly; the rest needs a proxy ([the preview decision](2026-11-24-preview-source-or-proxy.md)).
- The repo holds two toolchains: pnpm and Vite at the root, Cargo in `src-tauri/`. `pnpm check` runs both sets of checks ([architecture](../context/architecture.md) *Shape*).
- Frontend and backend talk only through Tauri IPC: commands from the frontend, events from Rust ([the ffmpeg decision](2026-11-24-rust-owns-ffmpeg.md)).
