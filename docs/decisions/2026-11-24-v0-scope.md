# v0 scope

Status: Accepted (2026-11-24).

## Context

v0's payoff is a Windows desktop app that does everything the advanced mode of [mgck's Discord GIF tool](https://mgck.ink/discordgifs) does, on any source the user's ffmpeg can read and at any size, including the AV1, HEVC and MKV files and multi-GB recordings the browser version fails on. mgck also has a simple mode and Discord-specific targets, and a desktop app invites packaging and platform work; none of that is needed for the payoff.

## Decision

v0 is advanced mode for one source at a time:

- Opening: drag-drop or a file dialog ([real paths](2026-11-24-real-paths.md)).
- Editing: trim (the selection); crop; width; frame rate; speed; direction (forward, reverse, boomerang); rotate and flip; top and bottom captions with text size.
- Format options: GIF colours and dithering; loop count; WebP quality; keep sound in MP4.
- Export: any mix of GIF, WebP and MP4 in one run; progress and cancel; results with Open and Show in folder.

Later, not in v0:

- Bundled or downloaded ffmpeg ([the user's ffmpeg](2026-11-24-users-ffmpeg.md)).
- mgck's simple mode, with presets and Discord size targets.
- Batches and queues.
- Code signing and auto-update.
- macOS and Linux testing ([Windows first](2026-11-24-windows-first.md)).
- CI.

Amendment 2026-11-24: copying an output to the clipboard moved into scope with epic VTG-9 (owner's decision for the desktop editor redesign) and was built in VTG-13: Copy in the Exports tab.

## Consequences

- mgck's advanced mode was the feature spec within this list. Since VTG-9 the UI follows the canvas boards ([the UI decision](2026-11-24-editor-ui-from-canvas.md)) and each setting keeps the behaviour it was ported with, mgck remaining the reference for how it was built; a feature in neither the scope nor the boards needs the owner's go-ahead.
- One source at a time means one open editor and one export run at a time; nothing needs a queue.
- Without CI, `pnpm check` run locally before each commit is the only gate.
- v0 is done when VTG-8, the Windows release build, is resolved.
